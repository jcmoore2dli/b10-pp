## COMPLETED JUNE 8–18

This covers two work blocks: the mid-June sprint (Week 13 scaffold domain work and cascading bug fixes) and the June 18 session (deploy bug discovery/fix, instructor-side UI and feedback parity work, and the AI provider portability audit).

### Linguistic Flexibility Scaffold Domain (FLEX_01–04)
- Fourth scaffold domain added alongside FRAME_01–06 and STRUCT_01–07
- Total scaffold criteria now 17 (was 13 as of June 7)
- Integrated into claudeScorer.js scaffold rubric lookup and prompt injection, same pattern as existing FRAME/STRUCT criteria

### Firebase Hosting Deploy Bug — found and fixed
- Manual `cp -r frontend/dist/* hosting/` deploys (used earlier in the sprint) didn't match the path structure Vite's `base: '/b10_practice_platform/'` config expects, causing fresh/uncached visitors to receive 404s on JS assets (browser would silently serve HTML instead, with MIME-type and "expected expression" console errors)
- Any browser with prior cache kept working, which masked the bug for hours — only fully fresh sessions or new devices showed it
- Root fix: `frontend/package.json`'s existing `npm run deploy` script (which nests output correctly under `hosting/b10_practice_platform/`) is now the only sanctioned deploy path, hardened with a `mkdir -p` safeguard so a missing destination folder can't silently skip the actual `firebase deploy` step
- Verification standard established: confirm via `curl -sI` on the actual deployed asset hash, checking for `HTTP/2 200` and `content-type: text/javascript` — never trust "Deploy complete!" or browser testing in an already-used tab alone

### Instructor-Side Bundle Sequence and Frames Practice Folders
- Instructor dashboard now mirrors the student-side collapsible folder pattern: a "Bundle Sequence" section (CORE passages grouped by `setNumber`, collapsed by default, shows attempted/total counts) and a "Frames Practice" section (grouped by `aesopWeek` W1–W6)
- Resolves the unwieldy flat-list roster view that was a known issue as of June 7

### S#.# Sub-Identifier Labeling
- Both the instructor's and student's Bundle Sequence views now show the `S{set}.{day}` triplet label (e.g., "S1.1") on each passage row, matching the label already shown in the assignment dropdown
- No new data required — assignment docs already carried `setNumber`/`dayNumber`
- This is what let the dedicated MTT CORE-only mode feature be dropped: an instructor can now just say "do Set 1, skip the ESO" using the existing structure, the same way a textbook page reference works, instead of needing a separate restricted account type

### Instructor Feedback Parity with Student FeedbackScreen
- The instructor's expanded attempt view previously showed only Transcript, Strengths, Gaps, Language Feedback, and Scoring Notes — a real mismatch with the richer feedback students see
- Added Summary (B2 student language note), the full Scaffold/Focus Feedback box (primary + secondary targets, Sustained/Developing/Emerging level pill, descriptor, evidence quote — same teal styling as the student view), and Transcript Note
- No new data plumbing needed: the `attempt` objects in the instructor dashboard already carry the complete submission document, including `summary` and `scaffold_feedback`, since they're queried directly from Firestore with no field-selection narrowing
- Applies retroactively to all previously completed scaffolded submissions — this is a display change reading already-stored data, not a scoring change, so nothing needs to be resubmitted
- Resolves June 7 item 5 ("scaffold feedback heading harmonization"), which turned out to be a larger gap than originally scoped — the actual fix was full content parity, not just matching headings

### AI Provider Portability Audit
- Read-only code audit confirmed the Anthropic dependency is genuinely architecturally swappable, not just nominally so
- Exactly three LLM call sites in the whole backend (`scoreTranscript`, `validateFeedbackGrammar` in claudeScorer.js; `generateProgressSummary` in index.js), all structurally identical, none using tool-use or system-prompt features
- Full findings and the specific mechanical edits a swap would require are documented in `governance/B10-PP_AI_Provider_Portability_Audit_v1.md`
- This gives the privacy compliance supplemental's "model-agnostic architecture" mitigation claim actual code-level evidence

- Progress summary by week / 4-week — tested end-to-end, working well

## ARCHITECTURE — CURRENT STATE

### Login Flow, Roster System, Scaffold Pipeline, Audio Retention
Unchanged from June 7 — see that document's Architecture section for full detail. The scaffold pipeline now also routes FLEX_01–04 through the same `SCAFFOLD_RUBRICS` lookup mechanism as FRAME/STRUCT criteria.

### Bundle/Frames Reference Pattern (new since June 7)
- Assignment docs' existing `setNumber`/`dayNumber` fields now drive both a collapsible grouped folder view (instructor and student) and an `S{set}.{day}` label shown inline on each passage row
- This reference-style pattern (instructor says "do Set 3" the way one would reference a textbook page) is what de-scoped both the MTT CORE-only mode feature and lowered urgency on bulk student assignment — see below

### Instructor/Student Feedback Parity (new since June 7)
- Both `FeedbackScreen.jsx` (student) and the instructor's expanded attempt panel in `InstructorDashboardScreen.jsx` now render the same fields (`summary`, `strengths`, `gaps`, `language_feedback`, `scaffold_feedback.primary`/`.secondary`, `transcript_note`, `transcriptText`) directly from the same submission document shape, with matching visual styling. The instructor view additionally retains a Scoring Notes panel (`monitor_notes`) that has no student-facing equivalent.

### AI Provider Dependency (new since June 7)
- See `governance/B10-PP_AI_Provider_Portability_Audit_v1.md` for the full architecture audit. Summary: three call sites, all using `@anthropic-ai/sdk`'s `client.messages.create()` with a single plain-text user message and no provider-specific features, API key bound via Firebase Secret Manager (`defineSecret("ANTHROPIC_API_KEY")`).
