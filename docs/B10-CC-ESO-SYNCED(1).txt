## 1. DOCUMENT OVERVIEW

### 1.1 Function

This file contains Extended Supported Opinion (ESO) prompts organized by domain and subdomain. Each prompt serves as a topic seed for passage generation using B10-CC-ALG algorithms.

### 1.2 Usage Protocol

1. Select domain (or allow random selection)
2. Select subdomain (or allow random selection)
3. Select question from subdomain
4. Consult algorithm tag for recommended generation approach
5. Execute algorithm per B10-CC-ALG procedures
6. Validate output per B10-CC-SPEC protocol

### 1.3 Algorithm Tag Key

| Tag | Algorithm | Best For |
|-----|-----------|----------|
| A01 | Research Finding Report | Research-framed questions |
| A02 | Policy Debate | Policy tension with counterargument |
| A03 | Trend Analysis | Emerging patterns with complications |
| A04 | Causal Explanation | "Why does X happen" questions |
| A05 | Institutional Critique | System/structural criticism |
| A06 | Nature/Science Narrative | Natural phenomena, biomimicry |
| A07 | Diagnostic Reversal | Correcting common assumptions |
| A08 | Public Health / Compliance | Health/safety regulatory gaps |
| A09 | Cross-Domain Connection | Unexpected field connections |
| A10 | Collective Response | Community adaptation to adversity |
| A11 | Technology Innovation | Novel technology mechanisms |
| A12 | Workplace Behavioral Pattern | Work behavior paradoxes |

## 16. USAGE NOTES

### 16.1 Algorithm Override

The algorithm tag is a RECOMMENDATION, not a constraint. Any question can be processed through any algorithm.

### 16.2 Counter-Intuitive Requirement

Regardless of algorithm, all passages must include a counter-intuitive element per B10-CC-SPEC Section 9.

### 16.3 Randomization Protocol

For balanced domain coverage, the bot should:
1. Track domains used in current session
2. Prioritize underrepresented domains
3. Avoid consecutive questions from same subdomain
