## COMPLETED THIS WEEK (June 1–7)

### Authentication
- Email login replaced with B10 ID + password
- Firebase Auth uses synthetic email internally: `{b10id}@b10pp.local`
- Admin accounts with real emails pass through as-is (detected by @ and .)
- Legacy student accounts with real emails still work via passthrough

### Instructor Account Creation
- New Cloud Function `createInstructorAccount` — creates Firebase Auth user and sets instructor role claims in one server-side call
- Admin panel now has "Create Instructor Account" section with B10 ID, password, group ID fields
- Green button, distinct from student access code creation

### Direct Roster System (replaces access code model)
- New Firestore collection: `/rosters/{instructorUid}/students/{b10Id}`
- Instructor looks up student by B10 ID via `lookupStudent` Cloud Function
- Cloud Function checks Firebase Auth — works regardless of how account was created
- "Add to Roster" button appears after successful lookup
- On add: `setStudentClaims` called to set student's b10Id token claim
- Token refresh on PassageMenuScreen if b10Id claim missing
- Firestore rules updated for `/rosters` collection

### SLT / Main Instructor Toggle
- Binary toggle in instructor dashboard header (MAIN / SLT)
- Persists to localStorage across sessions
- Assignment tagged with `instrRole` (main or SLT) on every assignment
- Student assignment feed shows colored dot: amber = main, teal = SLT

### Audio Deletion
- Changed from 14 days to 72 hours (accommodates full weekend)
- cleanupAudio Cloud Function runs daily, deletes audio older than 72 hours

### Scaffold Feedback Box
- All 13 rubric criteria (FRAME_01–06, STRUCT_01–07) wired into claudeScorer.js
- SCAFFOLD_RUBRICS lookup object injects relevant rubric per primaryTarget
- Output spec changed: scaffold_feedback is now structured JSON object with primary.level, primary.descriptor, primary.evidence, primary.target
- Scale: Emerging / Developing / Sustained
- Bug fixed: scaffoldConfig was being read from passage doc instead of assignment — now reads from sessionStorage
- Bug fixed: primaryTarget was only reading primaryFrame, never primaryStructure — now reads both
- Prompt tightened: scaffold_feedback must evaluate ONLY the specific frame/structure, not general argument quality
- Scaffold feedback box displayed in FeedbackScreen (immediate) with teal border, colored level pill
- Scaffold feedback box displayed in PassageMenuScreen My Progress view
- FeedbackScreen does fresh Firestore read if scaffold_feedback missing from navigation state

### Hide Assignment Feature
- Instructors can hide assignments they didn't create from their own view
- "Hide" button on each assignment row — does not delete, does not affect student queue
- hiddenBy array field on assignment doc; filtered on load
- Firestore rules updated to allow instructors to update hiddenBy field only

### Badge and Label Fixes
- Student passage card: gold "Focused" badge replaced with descriptive badge
  - Discourse frame → teal "Frames · [name]"
  - Grammar structure → indigo "Grammar · [name]"
  - Argument structure → steel blue "ARG · PSU Arc"
  - Combined → purple "Focus · [frame] + [structure]"
- ESO promptDescription fixed: now shows actual ESO question instead of "Listen carefully, then record your paraphrase"
- Date formatting fixed: uses calendar date comparison instead of 24-hour elapsed time

### Firestore Rules
- /rosters collection added with instructor-scoped read/write
- Assignment update rule updated to allow hiddenBy field updates by any instructor
- Assignment create rule relaxed (removed /students doc existence check for direct roster model)

## ARCHITECTURE — CURRENT STATE

### Login Flow
- Input: B10 ID (or real email for legacy/admin accounts)
- toSyntheticEmail(): if contains @ and . → use as-is; else → {b10id}@b10pp.local
- Firebase Auth stores synthetic email; never shown to user

### Roster System
- /rosters/{instructorUid}/students/{b10Id} — direct roster collection
- lookupStudent Cloud Function — verifies student exists in Firebase Auth
- setStudentClaims called on roster add — sets b10Id, role, groupId claims
- Old access code enrollment path still exists but not required for pilot

### Scaffold Pipeline
- Assignment stores scaffoldConfig with focusArea, primaryFrame, primaryStructure
- RecordingScreen reads scaffoldConfig from sessionStorage (set by PassageMenuScreen)
- Submission doc carries scaffoldConfig field
- processSubmission reads primaryFrame || primaryStructure for primaryTarget
- claudeScorer injects SCAFFOLD_RUBRICS[primaryTarget] into prompt
- Claude returns scaffold_feedback as structured JSON object
- FeedbackScreen and PassageMenuScreen both display scaffold feedback box

### Audio Retention
- Audio: deleted within 72 hours
- Transcripts: nulled after 30 days
- cleanupAudio runs daily on schedule
