## ARGUMENT STRUCTURE SCAFFOLD — DESIGN DECISION

- PSU (Point → Support → Universal) framework
- Claude's generic interpretation of "argument_structure" is close but not identical to PSU
- Key gap: "Support" in generic terms accepts illustration; PSU requires analytical move
- Decision: prompt addition closes this gap without boxing students into a template
- Post-pilot review: check scaffold_feedback outputs for argument_structure after Week 2
- If Claude tracks OPI rater judgment → leave alone; if not → add explicit PSU definition
